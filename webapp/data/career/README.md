# Career filesystem packs (Postgres optional)

Static unique JSON for `GET /api/mobile/v1/career/manifest` and
`GET /api/mobile/v1/career/file/:fileId`. Regenerated with:

```
npm run sync:career-fs
```

APK 20% stays in `mobile/assets/career` (start-here, shells, syllabus, batches 002/004/008/**041**, `hc_essential_v1`, HC drills + drafting). This folder is the remote ~80% (remaining Bar batches **003, 005–007, 009–040, 042–044** + `hc_canonical.json`).
